What staging and v5 source actually confirm

Modal scaling: Lumiverse uses body { zoom: var(--lumiverse-ui-scale) } and exposes --app-scaled-viewport-width/height. Spindle's resolveSpindleModalGeometry clamps to available viewport size. V5 calls ctx.ui.showModal({width:1440,maxHeight:980}) and its normal .ss-shell uses height: min(900px, calc(100dvh - 118px)). Requested width and shell height are separate limits.

Styles layout: Its 24fr / 46fr / 30fr split is fixed. Generate alone persists sidebar widths in the workspace storage contract. Styles width sliders need two new saved dimensions and explicit minimums.

Rendering: Stack rows duplicate the friendly title and filename as two distinct DOM nodes. Catalog cards currently display author, three badges and default weight. Both can be simplified in markup, not hidden with late CSS.

Theming: Lumiverse provides --lumiverse-surface, --lumiverse-surface-raised and fill variables; Studio currently derives most panel backgrounds from --lumiverse-fill and has some hardcoded mobile surfaces. An opt-in neutral surface mode can stay within the theme system.
