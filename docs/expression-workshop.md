# Expression Workshop (alpha.9.3)

Generation settings now has four sections: Character (identity, outfit and negative), Rendering (checkpoint, dimensions and sampling), LoRAs (saved stack, installed LoRAs, weights, enabled state, optional triggers), and Style (shared prefix, Swarm presets and shared negative). A Cast member can render without a linked character folder. These new character/model/stack overrides apply to the current open workshop; they do not edit the album recipe, identity or Genesis job. Restore inherited appearance/stack or select the inherited checkpoint to return to defaults. An explicitly empty override is not treated as inheritance. The existing per-set generation settings still persist as before.

Scroll past the gallery controls to reveal a centered quick-action pill above the footer. Select all or deselect all eligible expressions, add a custom slot, or open Generation settings without returning to the top. Later stages show only selection controls. The top stage navigator and footer Next / Skip remain unchanged. The rail uses compact accessible icons on narrow workshop widths, including host-scaled windows.

Remove background offers **Despill after background removal** (off by default), plus green or blue screen selection. It applies the same edge-only 70% despill as Studio Edit, on the original saved cutout at its native resolution. It keeps alpha unchanged and does not require an extra GPU job. A changed result is saved through the existing local edit PNG service with source provenance; unchanged results need no new upload. If the optional pass fails or is stopped, the cutout is retained. The existing 16-megapixel/8192px local editor and 7.5-million-character PNG data URL upload limits apply. This session-local checkbox is for the manual workshop only; Genesis is unaffected. Despill removes color contamination, not opaque background islands; use Edit's wand/eraser for those.

Regression: `python tests/expression-settings-browser.py` (Chromium, Playwright and Pillow), `node tests/backend-contract.mjs`, and `node tests/studio-edit-contract.mjs`.
