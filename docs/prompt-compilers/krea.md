# Krea 2

The [official prompting guide](https://github.com/krea-ai/krea-2/blob/main/docs/prompting.md) favors natural-language captions. An optional [expansion instruction](https://github.com/krea-ai/krea-2/blob/main/docs/expansion.txt) provides LLM-assisted caption expansion. Studio uses the common owned plan instead of introducing an extra model call. Describe composition, individual people, clothing and poses, visual style, lighting, and exact visible text. Standalone Booru quality/score metadata is not forced into the caption. Saved identity fragments and trained trigger strings remain user-supplied; the compiler is not a full tag-to-prose semantic translator. Use an appropriate Krea 2 recipe; choosing this compiler does not set CFG, resolution, steps, or switch models. FLUX.1 Krea is not Krea 2 and is not auto-detected as such.
